Flex is the platform behind the GOV.UK app. It runs serverless on AWS. It lets the app personalise
what it shows by bringing together:

- a user's GOV.UK app data and settings, such as their linked accounts and notification
  preferences
- the government services the GOV.UK app is built to work with

So each of those services can respond to a known person instead of an anonymous request.

Teams outside the platform write **domains**, which hold the logic behind personalised features.
Flex provides everything around the domains:

- a **Frontdoor** that checks, authenticates and routes every request
- a home for each **domain**, with its own API and its own path from development to production
- **gateways**, which give a domain access to other services. They validate everything that passes
  through them.

See [The platform](/flex-platform/start/platform/) for how the three parts fit together and what
exists today.
